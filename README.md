# Keystone Patch Panel

This 1U patch panel is designed for mounting keystone modules and is available in three widths: 10”, 19”, and half-rack (9.5”). Each width comes in two variants: a standard panel and one with added zip-tie posts for strain relief. Additionally, there are sparse versions where the keystone jacks are spaced further apart, allowing for larger (but fewer) modules.

Try it in your browser with the [web customizer](https://tomasf.github.io/keystone-patch-panel/), where you can choose the rack width, slot spacing and strain relief and download a ready-to-print 3MF file.

This model is fully parametric and written in Cadova, allowing you to easily adjust parameters in the source code to fit your exact needs.

This model uses [Cadova](https://github.com/tomasf/Cadova) and [my Keystone library](https://github.com/tomasf/Keystone).
Also available on [Printables](https://www.printables.com/model/1036170-keystone-patch-panel).
